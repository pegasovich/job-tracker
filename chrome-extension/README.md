# Job Apply AI Assistant (Gemini) — Chrome Extension

Расширение для Google Chrome, которое автоматически анализирует вакансию на сайте (DOU, Djinni, LinkedIn и др.) и генерирует персонализированное сопроводительное письмо (Cover Letter) с помощью бесплатного **Google Gemini API**.

---

## 🚀 Быстрый старт (Установка за 1 минуту)

1. Откройте Google Chrome и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
3. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Выберите папку:
   ```text
   C:\Users\pegas\job-tracker\chrome-extension
   ```
5. Расширение появится в списке и на панели Chrome! Закрепите его иконку (📌), нажав на значок пазла.

---

## 🔑 Настройка (Первый запуск)

1. Нажмите на иконку расширения **✨ Job Apply AI** в панели Chrome.
2. Вставьте ваш бесплатный **Gemini API Key**:
   - Если у вас ещё нет ключа, нажмите ссылку в окне: [Google AI Studio](https://aistudio.google.com/app/apikey) и создайте ключ в 1 клик (*Create API key*). Это бесплатно.
3. Нажмите кнопку **«Тест»**, чтобы убедиться, что ключ работает.
4. Проверьте или отредактируйте ваш профиль в блоке **«О кандидате»** (по умолчанию там уже заполнен шаблон QA Engineer).
5. Нажмите **«💾 Сохранить настройки»**.

## ⚡ Автозаполнение на любом сайте

1. Откройте страницу заявки и нажмите иконку расширения.
2. Нажмите **«⚡ Заполнить стандартные поля на этой странице»**.
3. Расширение заполнит распознанные пустые поля имени, фамилии, email, адреса, города, графства, почтового индекса, телефона, страны и дополнительных контактов. Если телефон начинается с международного кода, расширение выберет подходящий код страны и введёт национальную часть номера отдельно.
4. Проверьте результат и продолжите заполнение вручную. Отправлять форму расширение не будет.

Запуск работает по нажатию и получает временный доступ только к текущей вкладке. Если анкета встроена с другого домена, Chrome запросит отдельное разрешение для домена этой формы. Некоторые сайты используют нестандартные поля или собственные списки выбора; такие поля могут потребовать ручного ввода.

Адресные данные настраиваются во вкладке **«Анкета и автозаполнение»**. Для профиля по умолчанию заданы Cahersiveen, Kerry и Ireland. Улица, вторая строка адреса, Eircode и текст для поля **Find Address** не угадываются: укажите их в настройках, если хотите заполнять эти поля. Поле **Other Contact Details** по умолчанию содержит ссылки LinkedIn и GitHub; его можно отредактировать.

В PeopleHR поле **Find Address** служит для поиска адреса и не является полем Eircode: Eircode заполняется отдельно в **Post Code**, а Town/City, County/State и Address line 1/2 распознаются по видимым подписям формы. Страну в телефонном виджете PeopleHR расширение выбирает отдельно по международному коду из номера.

## 🎯 Как пользоваться на DOU / Djinni / LinkedIn

1. Откройте любую вакансию (например, на `jobs.dou.ua`).
2. Нажмите **«Відгукнутися на вакансію»** (или перейдите к блоку формы `#apply`).
3. Над полем *«Напишите немного о себе и о том, почему вакансия вам подходит»* появится панель:
   ```text
   [ ✨ Написать отклик с Gemini ]   [ ⚙️ ]
   ```
4. Нажмите **«Написать отклик с Gemini»**:
   - Расширение само считает название должности, компанию, обязанности и требования (*Responsibilities*, *Requirements*, *Will be a plus*).
   - Сгенерирует только готовый текст отклика: без анализа, чек-листов, черновиков и пояснений. Краткий формат — до 85 слов и 3–4 коротких абзаца; подробный — до 120 слов.
   - Текст автоматически вставится в поле. Вы сможете его просмотреть и при необходимости отредактировать перед нажатием «Отправить».
